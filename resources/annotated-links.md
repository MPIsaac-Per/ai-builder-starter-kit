# Annotated resources

## Engineering workflow

- [Matt Pocock's engineering skills](https://github.com/mattpocock/skills): composable skills for clarification, specifications, tickets, TDD, diagnosis, and review. Install from upstream so updates and licensing remain visible.
- [Skills installer](https://github.com/vercel-labs/skills): the installer used by `npx skills@latest add` for compatible agents.

## Agent workbench

- [BB](https://github.com/get-bb/bb): local-first workspace for steerable coding-agent threads, worktrees, provider choice, and extensible plugins.
- [BB site](https://getbb.app/): current desktop and `npx` entry points.

## Knowledge system

- [Obsidian data storage](https://obsidian.md/help/data-storage): explains vaults as local folders containing Markdown files.
- [Obsidian internal links](https://obsidian.md/help/links): supported link formats, headings, blocks, and rename behavior.
- [Obsidian CLI](https://obsidian.md/help/cli): current command-line installation and command reference.

## Testing

- [Node test runner](https://nodejs.org/api/test.html): standard-library test runner used by the example project.
- [Node test coverage](https://nodejs.org/api/test.html#collecting-code-coverage): line, branch, and function gates used by `npm test`.

## Resource acceptance rule

A new link should identify its owner, explain the job it helps complete, and prefer a primary source. Remove links that no longer support the documented command or workflow.
