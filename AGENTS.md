# Repository instructions

Delivery tier: TIER-1 pre-user.

- Read `CONTEXT.md` and `docs/spec.md` before changing behavior.
- Work in vertical slices through public interfaces.
- Write a failing behavior test before implementation.
- Keep the repository free of personal records, private company material, credentials, and machine-specific paths.
- Prefer standard-library code and narrow scripts. Justify every dependency.
- Run `./scripts/verify.sh` before claiming completion.
- Treat publishing, deployment, and external messages as human-approved actions.
- Record removal instructions for every added capability.
