# Maintained upstreams

Last checked: 2026-08-27

## BB

- Source: <https://github.com/get-bb/bb>
- Site: <https://getbb.app/>
- Start command:

  ```bash
  npx bb-app@latest
  ```

BB organizes provider-backed coding agents into steerable threads. A tracked `.bb/AGENTS.md` gives each BB thread repository instructions. A tracked `.bb-env-setup.sh` runs when BB creates a managed worktree.

## Matt Pocock's engineering skills

- Source: <https://github.com/mattpocock/skills>
- Installer:

  ```bash
  npx skills@latest add mattpocock/skills
  ```

Suggested first selection:

- `setup-matt-pocock-skills`
- `ask-matt`
- `grill-with-docs`
- `to-spec` and `to-tickets`
- `implement`, `tdd`, `diagnosing-bugs`, and `code-review`

Run `/setup-matt-pocock-skills` once per repository after installation.
