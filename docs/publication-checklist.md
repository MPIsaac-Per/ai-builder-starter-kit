# Publication checklist

Run this before creating or updating a public remote.

- [ ] `./scripts/verify.sh` passes.
- [ ] Git history contains no credentials, private email addresses, local user paths, or confidential material.
- [ ] Every external quotation and copied asset has a compatible license and attribution.
- [ ] Third-party skills remain upstream links unless their license and update plan justify copying them.
- [ ] The example contains invented data only.
- [ ] Repository visibility, owner account, license, topics, and description have been reviewed.
- [ ] Branch protection and required verification are configured after publication.
- [ ] The final diff has received human review.

Publishing is a separate human-approved action.
