# Contributing

## Choose a bounded change

Good first contributions include:

- Correct a setup instruction against its official source.
- Improve a template after using it on a real project.
- Add a failing setup case and its verified correction.
- Add a small example with a specification and behavior tests.
- Replace an outdated resource with its maintained primary source.

Do not submit personal records, credentials, confidential company material, or undisclosed product concepts.

## Work through the repository contract

1. Open or choose an issue with an observable outcome.
2. Record decisions in the issue or specification.
3. Add a failing behavior test when code changes.
4. Implement the smallest passing slice.
5. Run `./scripts/verify.sh`.
6. Open a pull request using the provided template.

## Pull requests

Keep one outcome per pull request. Include the verification command and output, files changed, removal instructions, and any human approval still required.

## Conduct

Participation follows [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
